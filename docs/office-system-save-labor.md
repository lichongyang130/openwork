# 办公系统省人工省心方案 — 从“人力硬扛”到“丢给它就行”

> 核心目标：**省人工 = 少做重复事，省心 = 不用盯、不会错、可回滚**
> 灵感：EvoX“真干活非吐文字” + 蜂群“复杂变简单并行” + Gene“越用越顺手”

---

## 1. 什么是省人工省心？定义标准

**省人工 3 层**：
- L1 单点省：写周报、整理发票这种单次任务，从30分钟→2分钟
- L2 流程省：会议→纪要→待办→日程→邮件，整条链自动跑，不用人搬运
- L3 决策省：合同审查、报销合规这种要判断的，AI先标风险，人只做Yes/No

**省心 4 要素**（来自视频金句反推）：
1. **不用配**：装完即用，不用API Key、不用绑卡、不用配环境，1500额度白嫖（抄EvoX）
2. **真干活**：不是吐一段文字就完，是真的建文档跑命令改文件，每步可见，报错自改
3. **不失忆**：教1遍记住，沉淀为Gene，下次复用，越用越顺手，解决“教100遍还是新手”
4. **可交付**：产出是单文件HTML/表格/可直接发的东西，不是干巴文字，发出去不用管

**衡量**：以前人力硬扛的环节，现在丢给它就行

## 2. 办公8大场景痛点与省心设计

来自 OpenWork 现有 `office` 场景 chips，逐个拆：

### 2.1 写工作周报 — 从翻记录到一键生成

**现在人力**：翻聊天记录、代码提交、会议纪要，30-60分钟拼凑，完成/数据/计划
**省心设计**：
- **侦查蜂分解**：读工作记录→提完成→提数据→提计划 3工蜂并行
- **真干活**：自动读 `workspace` 文件、git log、日历，生成 `周报_0520.md`，不是聊天框文字
- **Gene沉淀**：第一次教“我们周报结构是完成/数据/计划语气专业简洁”，固化为Gene，下次一键
- **可交付**：单Markdown+图表，发群里直接用

**省人工**：30分→2分，**省心**：不用翻记录

### 2.2 会议纪要整理 — 结论先行，待办自动进日程

**人力**：1小时会议，1小时整理纪要，再手动建待办
**省心设计**：
- **流程蜂群**：语音转文字→结论先行→决策/待办/负责人/截止时间 4工蜂
- **闭环**：待办自动写入日程+@负责人发邮件，不用人搬运
- **摇摆舞**：待办置信度低的标黄，需人工确认
- **Gene**：不同会议类型沉淀模板：周会/客户会/复盘会

**省人工**：60分→5分，**省心**：纪要→待办→日程自动闭环

### 2.3 邮件草拟 — 背景事项配合点得体

**人力**：想语气、列背景、怕遗漏配合点
**省心设计**：
- **模板蜂**：背景/事项/需要配合 3工蜂并行写，最后蜂王聚合
- **人话翻译**：把术语翻译成人话，例：SMTP配置→绑定邮箱
- **Gene**：老板/客户/同事不同语气Gene，GDI评分高的直接复用

### 2.4 文件整理 — 按类型分文件夹，重名加前缀

**人力**：下载文件夹乱，每周手动整理
**省心设计**：
- **自动化技能**：定时任务每天18点扫描新文件，按 文档/图片/表格 分，重名自动加日期前缀
- **真干活**：真的移动文件，不是列清单
- **可回滚**：整理前快照，错了可回滚，省心
- **Gene**：整理规则沉淀，下次新类型自动识别

### 2.5 发票报销整理 — 提取日期金额税号成表格

**人力**：一张张看发票，抄金额税号，易错
**省心设计**：
- **搜索蜂+分析蜂**：OCR提取→日期/金额/税号→整理成报销表 3工蜂
- **验证蜂**：金额求和校验，税号格式校验，标红异常
- **可交付**：单Excel可直接提交财务
- **合规**：发票合规检查Gene

**省人工**：100张发票2小时→3分钟，**省心**：自动校验不怕错

### 2.6 合同要点审查 — 标风险、权责不对等、缺失条款

**人力**：法务逐条看，3小时
**省心设计**：
- **维度分解**：风险条款/权责不对等/缺失条款 3工蜂并行
- **置信度**：每条风险带置信度+证据+建议修订
- **人机协作**：高风险必须人工审批，低风险自动标
- **Gene**：公司合同模板Gene，越审越准

### 2.7 通知公告拟稿 — 标题背景安排落款规范

**人力**：格式不规范，漏落款
**省心设计**：
- **模板蜂**：标题/背景/安排/落款 4工蜂，格式规范Gene
- **可交付**：单Word带公章位置

### 2.8 日程安排 — 按截止时间排优先级

**人力**：事项多，排不过来
**省心设计**：
- **调度蜂群**：按截止时间+重要性+工时，蜂群算法排程，类似蜂群觅食
- **冲突解决**：时间冲突标出，给3个备选方案
- **推送**：Telegram/Slack每天8点推送今日摘要（抄EvoX渠道接入）

## 3. 省心架构 — 4层设计（融合蜂群+EvoX）

### L0 零配置层（抄EvoX，解决劝退）

- Mac/Win客户端，装完即用，不用API Key，送1500额度白嫖
- 一键迁移Claude Code/Codex记忆
- 模型自由切：ChatGPT/Kimi/Grok/DeepSeek，同任务效果对比
- 额度可见，心里有数

### L1 真干活层（解决吐文字不干活）

- **不是聊天机器人**：右边执行面板，真的建文档跑命令改代码，每步可见
- **报错自改**：出错自己回头改，不是甩代码给你调（视频金句）
- **单文件交付**：产出是单HTML/Excel/Markdown，发出去不用管
- **可回滚**：操作前快照，错了回滚

### L2 蜂群流程层（解决复杂问题卡住）

- **Swarm开关**：对话框下打开，复杂任务拆3-8个简单问题并行
- **4角色工蜂**：搜索/分析/验证/案例
- **摇摆舞通信**：Pollen共享证据，避免重复试错
- **花粉库**：共享黑板，向量检索，冲突检测
- **蜂王聚合**：置信度加权+GDI评分，解决冲突，产出Honey Report

**办公流程示例：会议→纪要→待办→日程→邮件 5工蜂闭环**

### L3 自进化层（解决失忆）

- **自主进化开关**：右上角默认开，定期把修复优化存本机，关了不沉淀
- **Gene基因记忆**：有效经验固化为技能，第一次试错多，第二次复用更快，前后对比直观证据
- **GDI质量评分**：0-100分，基于复用次数成功率点赞
- **Marketplace**：搜全网别人分享gene，例搜“周报”出一列带GDI评分，直接复用，站在别人跑通经验上
- **越用越顺手**：教1遍记住，教100遍成专家

## 4. 省心机制 — 6个细节决定省不省心

来自视频“踩的坑一并说”启发：

1. **防错**：表单校验就地指出“手机号少2位”，不是“输入有误”；合同审查标红具体条款
2. **可取消**：加载超3秒给可取消，复杂任务可暂停
3. **少打扰**：通知推送值得打扰，具体胜吆喝“张三回复你报价问题”，同场景合并，22-8点免打扰，频率1次/天
4. **可追溯**：每步带source，发票带原图，报告带页码，证据链完整
5. **人机协作**：高风险必须审批，分解后可编辑子任务，解决“偶尔卡住需返工”
6. **多渠道推送**：Telegram/Slack/Discord/WhatsApp定时推送，例每天8点摘要，省事
