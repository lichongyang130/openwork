## 二、产品信息抽取

**产品名**：EvoX Agent
**出品**：EvoMap
**定位**：AI Agent 客户端，非聊天机器人
**系统**：Mac / Windows
**核心卖点**：
- 零配置：装完不用配API Key
- 1500免费额度，0门槛白嫖
- 多模型自由切：ChatGPT / Kimi / Grok / DeepSeek 等热门
- 真干活：建文档、跑命令、改代码，每步可见可回滚，报错自修复
- 自进化 Skills / Gene 基因记忆，越用越顺手，支持 GDI 质量评分市场
- 一键迁移 Claude Code / Codex 项目记忆
- 多渠道：Slack / Telegram / Discord / WhatsApp + 定时任务推送
- Swarm 多Agent并行（Beta）

**UI 三栏**：
- 左：会话和项目
- 中：对话框
- 右：干活过程面板（核心差异点）

**额度与模型**：
- 默认1500，界面可见消耗
- 模型切换同任务效果有差别
- 重活消耗不慢

## 四、两个实测案例深度拆解

### 案例一：本地大模型显存计算器（面向玩本地部署用户）

**痛点**：32B模型 Q4量化 上下文32K，现有显卡能不能跑？每次翻公式或问AI
**需求**：
- 单文件 HTML，离线打开即用，不联网
- 4输入：参数量、量化精度、上下文长度、KV缓存
- 实时出结果，暗黑界面，滑动条实时改变
- 发出去不用管

**Prompt 要点**：越具体越好，4输入+实时+暗黑+单HTML

**Agent 执行**：
- 右面板建文件、写代码、自检错误、报错自改（与普通AI甩代码区别）
- 耗时约2分钟

**结果**：
- 双击打开，输入32B Q4 32K，算出卡在边缘
- 滑动条拖动实时变
- 评价：界面配色一般，后又改一版，但一句话到可用物，一行代码没写，一次环境没配，完全自动化

**可复用 Gene**：单页工具生成经验

### 案例二：100多页资料变可视化报告（面向不想写代码用户）

**素材**：几份AI行业报告+几个网页，100多页
**痛点**：正常读一天
**操作**：直接拖进 EvoX Agent
**需求**：提炼核心观点 + 对比表格 + 带动态图表的网页，非干巴文字

**执行**：逐份读、逐份提取、归并，比较慢，需等待几分钟

**结果页结构**：
- 上：核心结论
- 中：不同家横向对比表格
- 下：可点可筛选动态图表

**特性**：单HTML文件，可发同事或丢网站

**价值判断**：比写代码更有价值，杂乱变可直接交出去的东西，以前人力硬扛，现在丢给它

## 五、自进化机制详解

**定义**：干完事有效经验总结成可复用技能存起来

**开关**：右上角自主进化，默认开，定期把问题修复、新优化自动存本机，关了不沉淀

**验证对比**：
- 第一次显存计算器：试错好几轮
- 第二次同类型单页工具：复用经验，按跑通路子走，更快试错少
- 前后对比 = 自进化有效最直观证据

**Marketplace**：
- 搜索 EvoMap 全网别人分享 gene
- 例：搜“写作”，出列表带 GDI 质量评分
- 直接复用，站在别人跑通经验上开工，效率提高

**评价**：思路认可，解决AI工具每次对话失忆痛点（教100遍还是新手），往越用越顺手方向，但Beta质量参差，有的可用有的不一定，实话实说

**相关概念**：
- Gene = 基因记忆
- GDI = 质量评分
- 沉淀位置：界面 Skills 列表

## 六、渠道与 Swarm

**渠道接入**：
- 路径：设置→连接
- 支持：Slack / Telegram / Discord / WhatsApp 等
- 场景：Telegram + 定时任务 每天8点整理关注信息源摘要推送
- 展示：今早收到信息，省事，实时热门新闻

**Swarm**：
- 位置：对话框下方开关
- 功能：多Agent拆任务并行干活
- 体感：复杂任务确实快
- 缺点：稳定性一般，偶尔卡住

## 七、Pros / Cons 原话提取

**Pros**：
- 不用配API Key，送1500额度，上手门槛几乎0，新手直接跑
- 真在动手干活，不是吐一堆文字，建文档跑命令改代码每步可见
- 自进化 Skills + 多渠道 方向对
- 完全自动化，一行代码没写，一次环境没配
- 单HTML可交付，发出去不用管

**Cons**：
- Beta版本，复杂任务偶尔卡住需返工
- 免费额度跑重活消耗不算慢
- 长期使用需考虑订阅或上自己Key
- 界面配色不算好看（案例一）
- 沉淀技能质量参差

**金句**：
- “它不是聊天机器人给你吐一段文字就完了，它是真的在你的电脑上建立文档跑命令改代码”
- “出错了它会自己回头改，而不是把一大堆代码甩给你自己去调”
- “从一句话到一个真正能用的东西，中间我一行代码都没写”
- “把杂乱材料变成一份能直接交出去的东西，这个环节以前都是人力硬扛的”
- “每次对话都是失忆状态，你教它100遍它还是新手”
- “它至少在往越用越顺手的方向做”
- “便宜常有，被偏爱不常有”→可迁移为会员/工具文案
